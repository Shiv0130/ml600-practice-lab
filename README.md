# ML600 Practice Lab

Static practice lab for **Machine Learning 600** (Richfield, lecturer Akhona Mdluli, exam Friday 20 November 2026).

Open the **commit-pinned** rawcdn URL (the latest pin is also in `version.json`):

`https://rawcdn.githack.com/Shiv0130/ml600-practice-lab/b8f1b30f0ad3212b7373083fabbd7b951abb04c6/index.html`

Scope is Akhona’s 15 exam pointers only (NumPy, Pandas, Scikit-learn, Matplotlib — no seaborn). Progress is saved in the browser (IndexedDB). Use **Download sync file** / **Load sync file** to move progress between devices.

This build adds:

- A **Videos** tab (`#/videos`) organised by the 15 exam pointers. Each pointer has Detailed (5–15 min) and Short (<5 min) YouTube videos, with a verified duration on the card. Nothing over 15 minutes is listed.
- **Celeste's walkthroughs** (Parts 1–3, try-it style) play in the lab when the `videos/` files are present, with chapter jump buttons. The MP4s are in the Celeste chat if the in-page player does not load.
- **You watched** badges on videos from Shivaar’s YouTube history (a **16 Nov** badge means a recent watch). Tick **Watched** to save progress — it is included in the sync file.
- The study-buddy circle, chat, mock export and “Ask” prompts now go to **Celeste** (the ML600 coach), not Liora.

Existing progress keys are unchanged. The mock exam at `#/mock` still mirrors PracticeQuestions.py (it is not LongQuestions_1).
